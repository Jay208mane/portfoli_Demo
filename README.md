# Jay Mane — AI-Powered 3D Personal Portfolio

A responsive dark portfolio starter customized using the details visible in the supplied LinkedIn and GitHub screenshots.

## Run locally
1. Extract the ZIP.
2. Open `index.html` in a modern browser. For the best experience, use a local server such as VS Code Live Server.
3. Internet access is needed for Google Fonts and the Three.js CDN. A CSS fallback is included if Three.js is unavailable.
